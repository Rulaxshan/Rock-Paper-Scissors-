# ✊ Rock Paper Scissors Game

A simple command-line Rock Paper Scissors game developed using Python. The player competes against the computer, which randomly selects Rock, Paper, or Scissors.

## 📌 Project Overview

This project is a beginner-friendly Python game that demonstrates fundamental programming concepts such as conditional statements, user input, random number generation, and decision-making.

## 🚀 Features

- User can choose Rock, Paper, or Scissors.
- Computer generates a random choice.
- Displays both player and computer choices.
- Determines the game result.
- Validates user input.

## 🛠️ Technologies Used

- **Programming Language:** Python
- **Module:** Random

## 🎮 How to Play

Enter a number according to the following options:

| Number | Choice |
|---|---|
| 0 | Rock |
| 1 | Paper |
| 2 | Scissors |

The computer will randomly select its choice, and the program will display the result.

## 📚 Concepts Practiced

- Variables and data types
- User input using `input()`
- Conditional statements (`if`, `elif`, `else`)
- Random number generation
- Basic Python programming logic
